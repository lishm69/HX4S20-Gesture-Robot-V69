# HX4S20 挥手切图与有声机器人 — V6.9

基于安路 EG4S20 的 FPGA 工程，融合 GP2Y0E03 距离传感器挥手切图、HDMI 图文显示、机器人视频与 HDMI 音频。

## 功能

- 图文模式下通过距离传感器识别挥手并切换图片。
- 遥控器 0 键进入或退出机器人视频模式；靠近时播放迎宾视频和中文配音。
- 保留音量调节、原图文、报警及相关显示功能。音频通过 HDMI 输出。

## 工程目录

- `src/td_project/HDMI_Side_Spectrum.al`：安路 TD 工程入口。
- `src/user_source/`：HDL 源码、IP 配置、约束和工程使用的音频文件。
- `tools/`：工程相关工具。
- [V69 融合工程与写卡烧录说明](V69_融合工程与写卡烧录说明.md)：使用、写卡及验证说明。
- [功能核查与图片自适应缩放检查报告](V69_功能核查与图片自适应缩放检查报告.md)。

仓库省略 TD 综合、布局布线等生成目录；完整工程、TF 镜像、固件、视频资源与验证资料请从 [V6.9 发布页](https://github.com/lishm69/HX4S20-Gesture-Robot-V69/releases/tag/v6.9) 下载 `HX4S20_V69_Full_Project.rar`。

## 使用与验证

使用 TD 6.2.1 打开工程入口，目标器件为 EG4S20BG256。上板需配套 TF 卡镜像和 V6.9 固件；具体操作参见工程说明。

该版本已完成仿真和构建验证，但全局时序尚未完全收敛（setup WNS -6.699 ns），固件为上板试验候选，实物运行稳定性仍需验证。
